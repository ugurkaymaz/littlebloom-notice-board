# LittleBloom Notice Board

A free WordPress plugin for nursery and preschool announcements. Includes sticky-note cards, a notice popup, customizable colors, and a public announcements archive.

## Release status

- **Version:** 0.3.6
- **WordPress.org:** Submitted on 29 October 2026; awaiting manual review.
- **Pro add-on:** Separate premium plugin (not included in this repository).

## Installation

Use the release package submitted to WordPress.org or install the contents of this repository as the `littlebloom-notice-board` folder within `wp-content/plugins/`. Activate **LittleBloom Notice Board** in WordPress.

## Development notes
